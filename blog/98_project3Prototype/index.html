Process

After doing some research on threejs and playing around with it on my local, I revisited our project concept and ultimately decided to scale down the project to implement functionalities that were more realistic while still maintaining the core concept of the original idea. After creating the github repo I went straight into establishing the basic layout. I had originally planned to use Vue, but decided that since the majority of the group was more familiar with nunjucks that it would be more time efficient in the long run to work in that direction. Then I transferred what I had done in my local to the repo, but realized that it was much too hardcoded and forced (it was using HTML and vite to create it's own local and network server), but I was working with it to see how much more user-end functionalities I can implement.

Questions

  1. Is the navigation intutitive? Should we provide instructions that it is a interactive 3D object?
  2. Other than the fact that it is a 3D object, I think it is relatively bland. Thoughts on how to make it more immersive?
  3. Does it seem like some kind of speculative/futuristic communication network? What can we do to make it more so?
